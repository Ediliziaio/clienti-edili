COPERTINE ARTICOLI BLOG — ClientiEdili
=======================================
Per dare una copertina a un articolo, metti qui l'immagine con il nome
ESATTO dello slug dell'articolo + .jpg (consigliato 1200x750 px, 16:10).

Esempio: la copertina dell'articolo /blog/google-ads-imprese-edili
va salvata come:  public/blog-covers/google-ads-imprese-edili.jpg

Finché il file non esiste, l'articolo mostra una copertina di fallback
(nessuna immagine rotta). Elenco file attesi (dal più recente):
